Nothing was re-annotated or re-graded. The severity grades and lesion boxes are the original authors' annotations.

- **Severity** is the primary label: `level` from 0 to 3, and `severity` as a word (mild, moderate, severe, very severe).
- **Lesion-count label** is kept as released. It mixes lesion count with severity in a way the original authors did not fully document, so use `level` for severity.
- **Folds.** The five test folds are close to, but not exactly, a partition of the images: a few images appear in more than one test fold. This comes from the original release. The canonical `split` column uses fold 0 only, which is a clean split.
