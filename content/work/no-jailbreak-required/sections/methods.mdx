**Requests.** 100 prompts sampled from the AdvBench harmful behaviors benchmark (Zou et al., 2023).

**Conditions.** Each request was sent to each model as an ordinary user would send it: no system prompt, and no jailbreak technique of any kind.

**The exploitable gap.** A request is in the gap when at least one model complies and at least one refuses. A request every model refuses is handled; one every model complies with is a shared failure.
