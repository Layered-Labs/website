Nothing a person records or types leaves their device. There is no account and no server that receives audio or text: the recording, the voice profile and the messages are stored in the browser's own storage, and deleting a voice removes it.

The only network traffic is a one-time download of the app, its code libraries and fonts, and the public model files. Where the browser reports that it is on mobile data or data saver, Wellspring asks before downloading the model.
