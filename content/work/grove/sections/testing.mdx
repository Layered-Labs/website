We are looking at two things.

### Access

- How many steps, and how much waiting, it takes to get from a link to a first answer.
- Which phones and laptops can run the model, and how fast.
- What happens on a device without WebGPU.

### Quality

- Where a 0.5B-parameter model does well. We expect tasks such as rewriting, explaining a simple idea and drafting a short message to suit it best.
- Where it fails. We expect arithmetic, facts it has to recall, long reasoning and languages other than English to be hard.

These are expectations we want to measure, not results. We have not benchmarked Grove yet, so this page makes no claims about accuracy.
