A model that runs on the device keeps data on the device, works without a connection and costs nothing per question. Running one has usually meant capable hardware and some setup. Our [NYC Clinic AI Infrastructure](https://huggingface.co/datasets/Layered-Labs/nyc-clinic-ai-infrastructure) dataset shows how uneven access is, even inside one city: across 311 ZIP codes, the lowest has broadband in only 33.6% of households. If local models are going to reach more people, it helps if they run on hardware people already have.

Nearly every device has a web browser. WebGPU lets a browser use the device's graphics chip, so a small open-source model can run in it from a link, with nothing to install. Grove is an experiment to find out how well that works: how easy it is to reach, and where a model this small does well and where it fails.
