Grove asks one question: can a small open-source language model run through WebGPU, so that anyone with a web browser can use a local model, without expensive hardware or anything to install?

A model that runs on the device keeps data on the device, works without a connection and costs nothing per question. Running one has usually meant capable hardware and some setup. Our [NYC Clinic AI Infrastructure](https://huggingface.co/datasets/Layered-Labs/nyc-clinic-ai-infrastructure) dataset shows how uneven access is, even inside one city: across 311 ZIP codes, the lowest has broadband in only 33.6% of households. If local models are going to reach more people, it helps if they run on hardware people already have. Nearly every device has a web browser.

So Grove is a plain chat that runs one small model in the browser. We are watching two things: how easy it is to reach, and where a model this small does well and where it fails. It will not match the large hosted models, and it is not meant to.
