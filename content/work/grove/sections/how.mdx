The model files download once, a few hundred megabytes, from Hugging Face. The browser keeps them, so later visits open straight into the chat and work with no connection.

We are testing how many steps and how much waiting it takes to get from a link to a first answer, and which phones and laptops can run it. For quality, we expect a 0.5B-parameter model to suit rewriting, explaining a simple idea and drafting a short message, and to struggle with arithmetic, recalling facts, long reasoning and languages other than English. These are expectations we want to measure, not results: Grove has not been benchmarked yet.
